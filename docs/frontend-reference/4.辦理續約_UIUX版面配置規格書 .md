# 辦理續約－UI/UX 版面配置規格書

版本：2026/10/18。

## 1. 頁面定位

教練由目前購課方案進入獨立「辦理續約」頁，每次建立一門課程的新購課方案，與原方案建立續約關聯。支援同課程續購與不同課程加購，不將堂數加回舊方案。

## 2. 共用 Layout 與視覺

- 採提供的確定導覽列：置中橘色六角閃電啞鈴 Logo、POWER GYM、力量健身與教練標示。
- 純文字選單依序為首頁、學員清單、我的課表、學員出席、續約與關懷；最後一項亮橘底白字選中。
- 底部保留 POWER GYM 及「持續運動，讓改變成為日常。」。
- 主色暫用 `#F97316`，白色圓角卡片、淺灰背景、深色文字、細框與適當留白；正式共用色碼以團隊 Layout 為準。
- 不新增其他導覽項目，不顯示會員等級或右上方會員登入身分。
- 桌面參考圖為單張 16:9；實作可捲動，不鎖死畫面高度。

## 3. 頁首

- 左箭頭「返回方案詳情」。
- 主標題「辦理續約」。
- 副標題「為學員建立新的購課方案，原方案紀錄與剩餘堂數保留。」。
- 不顯示「04」等示意頁序。

## 4. 主內容配置

桌面三欄由左至右為原方案資訊、新購課方案、續約資料。續約資料欄可稍寬，欄位高度及間距一致。窄螢幕依相同順序改為單欄。

### 4.1 原方案資訊

全部唯讀，使用文字或淺底資訊列，不使用可編輯選單：

| 欄位 | 示意內容 |
| --- | --- |
| 會員 | 小美 |
| 原方案編號 | #001 |
| 課程 | 重訓課 |
| 教練 | 林教練 |
| 購買日 | 2026/07/01 |
| 剩餘／總堂數 | 2／20 堂 |

方案編號與購買日保留，讓教練知道本次從哪筆方案辦理；正式內容依查詢結果顯示。

### 4.2 新購課方案

| 欄位 | 呈現與行為 |
| --- | --- |
| 課程＊ | 單選下拉，預設原課程；僅列登入教練目前可授課項目 |
| 教練 | 登入教練姓名，唯讀 |
| 購買堂數＊ | 正整數輸入、初始空白，提示「請輸入堂數」，旁標「堂」 |

課程下方說明：「可選目前教練可授課的其他課程」。區塊底部：「每次限購一門課程；其他課程請另筆辦理。」。

不預填示意堂數 20，不讓教練選購課狀態 status。教練固定為登入者且不可切換；跨教練購課由管理端處理，不在本頁列出其他教練或其專屬課程。

### 4.3 續約資料

| 欄位 | 呈現與行為 |
| --- | --- |
| 本次購課金額（NT$）＊ | 初始空白，提示「請輸入金額」；手工輸入本次全部購買堂數的總金額，僅接受非負整數，不自動計價 |
| 付款方式＊ | 單選下拉，初始「請選擇」；選項固定現金、轉帳、信用卡；依序對應 cash、transfer、card |
| 購買日期＊ | 可操作日期選擇器，附日曆圖示，預設台灣今天，格式 YYYY/MM/DD；小字「可補登過去購課日期，不可選未來日期」；可選範圍為原方案購買日至今天（含當日） |
| 備註（選填） | 多行框，提示「請輸入備註」，右下字數 0／500 |

付款方式是在登錄付款資訊，不提供刷卡、跳轉支付或自動扣款介面。本次示意購買日 2026/10/18 不是固定預設值。購買日期只選日期，不要求填時間；系統另自動記錄續約登錄時間，不增加可編輯的登錄時間欄位。

## 5. 底部提示與按鈕

淺橘資訊區：

> 確認後將建立一筆新購課方案，並與原方案建立續約關聯。原方案剩餘堂數保留，不合併至新方案。

右下依序為框線「取消」及亮橘主要按鈕「確認續約」。

## 6. 操作回饋

- 以「＊為必填」說明搭配課程、堂數、金額、付款方式、購買日期標示；備註不標必填。
- 錯誤訊息顯示在欄位下方，焦點移至首個錯誤。購買日期晚於今天時顯示「購買日期不可晚於今天」；早於原方案購買日則顯示「購買日期不可早於原方案購買日」。
- 初始資料載入前不開放提交；載入失敗提供重試，不以示意值代填。
- 送出中顯示「辦理中…」，停用提交與可編輯欄位，避免重複操作。
- 失敗保留輸入與錯誤提示；成功顯示「續約已完成」，回原方案概況並更新資料。
- 有未儲存變更時，取消或站內離開先確認；確認取消不寫入。
- 成功後如需再買另一門課，從原方案再次點擊辦理續約。

## 7. 可用性與設計界線

欄位可用鍵盤操作、焦點清楚、標籤與輸入關聯；不只靠顏色表達錯誤。共用導覽縮排由團隊 Layout 處理。完整保留表單與按鈕，不把交易、資料表或全部業務規則塞進畫面。

## 8. 已定案狀態與停用會員呈現

- 本頁不新增可編輯 status 欄位；新方案由後端寫入 active。方案狀態依剩堂同步：大於 0 為 active（使用中），0 為 usedup（已用完）；更正補堂後恢復 active。
- 完成續約不表示原方案用完，不改寫其剩餘堂數；沒有到期日，不呈現 expired。
- 會員啟用／停用與方案使用狀態分開，不以會員停用把方案顯示成已用完。
- 停用會員進入本頁時，頁首下方顯示「此會員已停用，請先恢復會員後再辦理續約」。保留有權查看的原方案摘要及返回入口，表單停用，「確認續約」按鈕停用；不提供恢復會員按鈕。
- 若送出時才得知會員已停用，顯示同一提示並停止提交，不顯示成功訊息，保留返回方案詳情入口。
- 方案詳情的「辦理續約」入口對停用會員亦停用，並說明原因；歷史查閱保留。既有出席更正入口仍依出席模組的權限與更正規則提供，不在本頁新增出席編輯介面。
- 停用不刪除購課、預約、出席、跟進或續約歷史，不清空剩堂；此為系統行為要求，不把全部規則文字塞進表單。
- 付款方式正式選項為現金、轉帳、信用卡，初始仍顯示「請選擇」，未選前不得送出；中文與英文代碼分開呈現及儲存。
