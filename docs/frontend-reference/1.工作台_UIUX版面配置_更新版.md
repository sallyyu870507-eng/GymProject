# 續約與學員關懷工作台－UIUX版面配置提示詞

請設計「續約與學員關懷工作台」的網頁 UI mockup。

## 1. 整體風格

- 輸出單張 16:9 橫向、高解析度完整工作台畫面。
- 全介面使用清楚可讀的繁體中文。
- 使用白色卡片、淺灰背景、深色文字與圓角設計。
- 主色使用亮橘色 #F97316，搭配淺橘底。
- 主要按鈕、選中狀態使用亮橘或淺橘底，文字保持足夠對比。
- 分類辨識色：優先聯繫為紅色、堂數將盡為橘色、久未到課為藍色、已用完為灰色。
- 側邊導覽沿用確定版 POWER GYM：六角形啞鈴閃電 Logo、「力量健身」、教練角色標籤。
- 無圖示文字選單依序為「首頁、學員清單、我的課表、學員出席、續約與關懷」，選中「續約與關懷」，使用亮橘底白字。
- 側欄底部顯示 POWER GYM 與「持續運動，讓改變成為日常」。
- 右上角顯示「林教練／教練」。

## 2. 標題區

標題：「續約與學員關懷工作台」。

副標題：「依剩餘堂數與出席情況，安排續約與關懷」。

## 3. 統計卡片

同一列顯示四張可點擊卡片，包含標題、數量與簡短說明：

- 優先聯繫：2 筆。

    說明：「剩餘 1～5 堂，尚未完成續約」。

- 堂數將盡：2 筆。

    說明：「剩餘 6～10 堂，尚未完成續約」。

- 久未到課：3 筆。

    說明：「尚有剩堂，同課程至少 14 天未出席」。

- 已用完：1 筆。

    說明：「剩餘 0 堂，尚未完成續約」。


卡片下方顯示：

「以購課方案計數；同一方案可能符合多項條件，各項數量不可直接加總。」

## 4. 查看範圍

使用分段切換控制項：

- 「全部待追蹤」：預設選中。
- 「所有方案」：未選中。

旁邊簡短說明：

「所有方案包含有權查看的歷史與現在購課紀錄。」

## 5. 搜尋與篩選列

依序呈現：

- 會員姓名輸入框，提示文字「搜尋目前範圍內的會員姓名」。
- 搜尋按鈕。
- 追蹤分類下拉選單。
- 跟進狀態下拉選單。
- 清除篩選按鈕。

追蹤分類選項：

全部、優先聯繫、堂數將盡、久未到課、已用完。

跟進狀態選項：

全部、未聯繫、尚未取得回應、考慮中、同意續約、無意願。

兩個下拉選單預設顯示「全部」，保持收合。

## 6. 方案列表

目前為「全部待追蹤」，標題顯示「待追蹤方案」，右側顯示「共 6 筆」。

表格欄位：

會員、課程／方案編號、購買日、剩餘／總堂數、同課程最後出席日、追蹤分類、跟進狀態、操作。

呈現規則：

- 同一購課方案只出現一列。
- 同一會員不同方案分別列出。
- 追蹤分類可顯示多個彩色標籤。
- 跟進狀態放在「追蹤分類」與「操作」之間，單獨一欄，每筆只顯示一個最新狀態。
- 沒有跟進紀錄才顯示「未聯繫」；已聯絡但電話未接或訊息未回，顯示「尚未取得回應」。長標籤可換行。
- 已完成續約者，在課程／方案編號下方顯示「已完成續約 → 新方案 #編號」。
- 沒有追蹤分類顯示「—」。
- 同課程完全沒有出席紀錄時，顯示「尚未出席」。
- 每列提供「查看詳情」按鈕。
- 切換為「所有方案」時，列表標題改為「購課方案列表」。

## 9. 設計限制

- 只畫目前工作台，不畫方案詳情、跟進表單或續約表單。
- 不使用「即將到期」，因方案沒有設定到期日。
- 不將所有業務規則塞進畫面。
- 保持表格文字清晰；長欄名及多重標籤可適度換行。
- 輸出具體網頁 UI，不輸出流程圖或多頁拼圖。
