# 方案詳情－方案概況：UI/UX 版面配置

版本：2026/10/18。依使用者本次確認的亮橘 POWER GYM 配置圖整理。

## 1. 設計目的與輸出

設計教練從續約與關懷工作台點「查看詳情」後的方案詳情頁，預設選中「方案概況」。輸出單張 16:9 高解析度繁體中文網頁 mockup；只呈現此分頁，不拼接其他頁面。

## 2. 共用 Layout

- 白色側欄、淺灰主內容背景、白色圓角卡片、深色文字。
- 主色亮橘 #F97316；淺橘用於提示底色與圖示背景。
- 側欄上方為 POWER GYM 六角形啞鈴閃電 Logo、「力量健身」及「教練」角色標籤。
- 文字選單依序：首頁、學員清單、我的課表、學員出席、續約與關懷。
- 「續約與關懷」以亮橘底白字選中，其餘選單不選中。
- 側欄底部為 POWER GYM 及「持續運動，讓改變成為日常」。
- 頂部白色橫列顯示「方案詳情」。本版不另放右上角登入者頭像區。
- Layout 由共用元件提供，不在功能頁重複實作。

## 3. 返回與標題區

- 主內容左上顯示亮橘「← 返回工作台」。
- 主標題為「小美・重訓課・方案 #001」。
- 同一列右側為「＋ 新增跟進」橘框按鈕及「辦理續約」亮橘實心按鈕。
- 每個按鈕只出現一次，不在概況卡內再增加重複入口。

## 4. 會員摘要卡

橫向排列：會員頭像／姓名、性別、年齡、電話、電子信箱，以細分隔線分組。

示意：小美、女、28 歲、0912-345-678、mei@fitness.com。

- 年齡由生日計算；此區不顯示生日計算公式。
- 不顯示「一般會員」或會員等級。
- 沒有頭像時使用姓名首字圓形占位。
- 電話或信箱過長可換行，不能遮住其他欄位。

## 5. 分頁列

依序為「方案概況」「跟進紀錄」「出席與體態」。

- 方案概況使用亮橘文字及底線表示選中。
- 另外兩頁籤使用深灰文字。
- 一次只顯示一個分頁內容；會員摘要、標題與主要操作入口保留。

## 6. 方案概況卡

卡片標題「方案概況」，內容左右兩欄：

| 左欄 | 示意值 |
|---|---|
| 課程 | 重訓課 |
| 教練 | 林教練 |
| 購買日 | 2026/07/01 |

| 右欄 | 示意值 |
|---|---|
| 總堂數 | 20 堂 |
| 已使用堂數 | 18 堂 |
| 剩餘堂數 | 2 堂 |
| 最近一次上課 | 2026/10/15 |

- 左右欄以細直線區隔；右欄各列可用細橫線分隔。
- 最近一次上課下方小字為「同課程・同教練」，不加「（跨方案）」。
- 日期計算範圍為此會員同課程、同教練跨方案的最後實際出席日；此為資料規則，不將整段寫入畫面。
- 堂數皆為目前方案的值，不跨方案加總。

## 7. 關懷提醒

概況卡底部為淺橘提示區，包含警示圖示與文案：

「剩餘 2 堂，建議主動聯繫，了解續課意願。」

這段只適用於示意方案尚未完成續約時；正式資料須依功能規格動態顯示，不把此句固定套用所有方案。

## 8. 空值與其他狀態

- 同課程從未出席：最近一次上課顯示「尚未出席」。
- 生日不明：年齡顯示「—」；聯絡欄位不明亦顯示「—」。
- 載入中、查詢失敗、無權限及不存在方案依功能規格處理，不用示意數字充當真實資料。
- 已續約方案的提示文案會改為完成資訊；同時久未到課時仍保留關懷提醒。

## 9. 限制

維持附圖的欄位與層次。不新增購課、付款或跟進表單，不增加會員等級、圖表或跟進時間軸；其餘分頁另行設計。
