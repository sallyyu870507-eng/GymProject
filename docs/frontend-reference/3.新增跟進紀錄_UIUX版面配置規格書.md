# 新增跟進紀錄－UI/UX 版面配置規格書

版本：2026/10/18。

## 1. 頁面目的與範圍

依確認畫面設計教練端「新增跟進紀錄」獨立頁面，記錄目前購課方案的一次聯絡嘗試或聯絡結果。本文件定義配置、視覺與互動呈現；資料驗證及寫入依同名功能規格書。

## 2. 整體風格與共用 Layout

- 桌面版以單張 16:9 橫向完整畫面為設計參考；實作不固定高度，內容超出時可捲動。
- 全介面使用繁體中文；白色卡片、淺灰背景、深藍黑文字、圓角與細框線。
- 主色暫用亮橘色 `#F97316`，由共用主題變數管理，正式色碼以團隊 Layout 為準。
- 主要按鈕與導覽選中狀態使用亮橘色，文字須有足夠對比。
- 左側導覽沿用確認版本：置中六角形橘色閃電啞鈴 Logo、POWER GYM、力量健身、教練身分標示。
- 導覽依序為「首頁、學員清單、我的課表、學員出席、續約與關懷」，使用純文字選項；「續約與關懷」為橘底選中狀態。
- 底部保留 POWER GYM 與「持續運動，讓改變成為日常。」。
- 不額外加入報表分析、系統設定或未確認的登入者區塊。

## 3. 頁首與導覽

- 內容區左上提供左箭頭與「返回方案詳情」。
- 主標題「新增跟進紀錄」。
- 副標題「記錄與學員的聯繫內容，持續追蹤並維持良好互動。」。
- 本頁為獨立頁，不使用彈窗或抽屜。

## 4. 方案摘要列

在標題下方使用淺底圓角摘要列，依序顯示：

| 項目 | 示意內容 |
| --- | --- |
| 會員頭像／姓名首字 | 小 |
| 會員姓名 | 小美 |
| 課程 | 重訓課 |
| 方案編號 | 方案 #001 |
| 剩餘／總堂數 | 剩餘 2／20 堂 |

摘要唯讀，不提供重新選擇會員或方案；各項以適度留白或直線分隔。示意資料不得作為正式預設值。

## 5. 表單配置

使用一張白色圓角卡片，包含以下區域：

### 5.1 本次聯繫時間

- 第一列標籤「本次聯繫時間」。
- 日期時間輸入框可選日期＋時分，採 24 小時制，附日曆圖示；可使用 `datetime-local`，步進 60 秒。
- 預設 Asia/Taipei 現在時間，取至分鐘；示意顯示 `2026/10/18 14:21`，正式值動態產生。
- 允許補登過去日期時間，不可晚於現在；錯誤提示「本次聯繫時間不可晚於現在」。
- 僅擴寬原日期控制項以容納時分，不調整其他區塊配置。
- 顯示格式 `YYYY/MM/DD HH:mm`，不顯示秒；送出時保留日期與時分，秒數為 00。

### 5.2 聯絡方式與跟進結果

桌面版同列兩欄，窄螢幕改為上下排列。

| 控制項 | 內容 |
| --- | --- |
| 聯絡方式 | 單選下拉，示意及預設顯示「電話」 |
| 跟進結果 | 單選下拉，示意及預設顯示「尚未取得回應」 |

聯絡方式選項採「電話、訊息、當面、其他」；此為本頁補充的實作選項，並非由圖片或既有 API 推定。

跟進結果固定四項：「尚未取得回應、考慮中、同意續約、無意願」。下拉保持收合。

選「尚未取得回應」時，下方顯示：「已嘗試聯絡，尚未取得會員回應。」；其他結果不顯示這句不適用的說明。

### 5.3 聯繫內容

- 標籤「聯繫內容（選填）」，不加必填星號；四種跟進結果皆可留白。
- 多行文字框，提示文字「請輸入本次聯繫內容…」。
- 右下角顯示字數，例如「0／500」，上限 500 字。
- 保留足夠高度，支援換行；未填或只有空白仍可儲存，不顯示必填錯誤。
- 如約定下次聯絡時間，直接寫入內容，例如「約定 10/25 再次聯絡」。
- 不提供「下次追蹤日期」輸入欄位，也不暗示會自動提醒。

## 6. 提示與操作區

表單底部左側簡短提示：

> 跟進結果：尚未取得回應、考慮中、同意續約、無意願。
>
> 未聯繫由系統依「無跟進紀錄」判定，不提供選取。

右側依序為次要框線按鈕「取消」與亮橘主要按鈕「儲存跟進紀錄」。主要按鈕下方顯示「儲存後返回跟進紀錄。」。

## 7. 互動與回饋

- 僅本次聯繫時間、聯絡方式、跟進結果為必填，標題加 `＊`；表單註明「＊為必填」。聯繫內容標示「選填」，不得顯示所有欄位皆必填。
- 欄位驗證失敗時，在對應欄位下方顯示具體錯誤，並將焦點移至第一個錯誤欄位。
- 儲存中主要按鈕顯示「儲存中…」，表單與離開操作暫停，避免重複送出。
- 儲存失敗保留已填內容，顯示錯誤與可重試操作。
- 儲存成功顯示「跟進紀錄已儲存」，返回同方案「跟進紀錄」分頁。
- 取消或返回不儲存；有變更時提示「尚有未儲存的內容，確定離開？」。
- 初次載入顯示骨架或載入提示，資料完成前不開放儲存。

## 8. 響應式與可用性

- 表單控制項有明確標籤，可透過鍵盤操作；焦點樣式清楚可見。
- 不以顏色作為唯一辨識方式。
- 窄螢幕摘要可換行、表單改單欄；導覽由團隊共用 Layout 處理。
- 不將資料表名稱、API 欄位或全部業務規則塞進畫面。
