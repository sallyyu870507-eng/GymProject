# 方案詳情－跟進紀錄：UI/UX 版面配置規格書

版本：2026/10/18。

## 1. 頁面與共用版面

本頁為方案詳情的「跟進紀錄」分頁，沿用已確認的方案概況共用頁首及會員摘要，不另做會員選擇器。

- 白色側邊導覽、POWER GYM 六角閃電啞鈴標誌、力量健身及教練標示。
- 純文字選單：首頁、學員清單、我的課表、學員出席、續約與關懷；最後一項亮橘底白字選中。
- 底部 POWER GYM 與「持續運動，讓改變成為日常。」。
- 主色 #F97316，白色圓角卡片、淺灰背景、深色文字；正式顏色依共用 Layout 統一。
- 頂部「方案詳情」、返回工作台、標題「小美・重訓課・方案 #001」。
- 頁首右側僅一組「新增跟進」框線按鈕及「辦理續約」亮橘按鈕。
- 會員摘要沿用頭像、姓名、性別、年齡、電話、電子信箱；不顯示會員等級。
- 分頁：方案概況、跟進紀錄、出席與體態；跟進紀錄以亮橘字及底線選中。

## 2. 紀錄區

- 標題「跟進紀錄」，右側顯示符合目前方案的總筆數。
- 使用由新到舊的垂直時間軸及紀錄卡片。
- 每筆顯示本次聯繫時間 YYYY/MM/DD HH:mm、聯絡方式、跟進結果、紀錄教練與聯繫內容。
- 時間軸點使用橘色；聯絡方式及結果用文字標籤，不能只靠顏色辨識。
- 聯繫內容保留換行與長文換行，不截掉無法另行閱讀的內容；空白顯示「—」。
- 區塊內不再放第二個新增跟進按鈕。每筆卡片右上角提供小型橘色框線「編輯」按鈕，可搭配鉛筆圖示；不提供刪除。
- 不獨立顯示下次追蹤日期；聯繫內容若有約定日期，原文呈現，不產生提醒。

## 4. 分頁與狀態

- 每頁 10 筆，顯示總筆數、目前頁碼、上一頁及下一頁；首尾頁對應按鈕停用。
- 示意圖共 3 筆、1 頁，兩側按鈕停用。
- 載入中顯示骨架；錯誤顯示「跟進紀錄載入失敗」及重試，保留有效共用頁首。
- 無紀錄顯示「此方案尚無跟進紀錄」，保留頁首新增跟進入口，不多放重複按鈕。
- 無權限或方案不存在時不顯示個資，提供返回工作台。
- 停用會員仍可於權限內查看歷史；辦理續約入口停用並提示須先恢復會員。新增跟進沿用其既有方案權限規則，不因本頁自行新增限制。

## 5. 底部說明與可用性

「本頁僅顯示目前方案的跟進紀錄；同意續約不代表已完成購課。」

窄螢幕保持相同閱讀順序，摘要及標籤可換行。分頁及按鈕支援鍵盤與清楚焦點。時間是會員聯繫時間，不標示為系統建立時間。

## 6. 編輯入口與共用表單（本次新增）

- 三筆示意紀錄各自右側顯示一個「編輯」，位置一致，不遮蔽內容；窄螢幕可換行。
- 點擊前往獨立「編輯跟進紀錄」頁，沿用新增跟進的版面及表單元件；本次列表畫面不另畫編輯頁或彈窗。
- 表單帶入原聯繫時間、聯絡方式、跟進結果及聯繫內容；不重設為現在或新增預設值。
- 會員與方案摘要唯讀，紀錄教練不可切換；可編輯四項欄位沿用新增驗證，內容仍選填最多 500。
- 主要按鈕「儲存修改」，次要「取消」；上方返回跟進紀錄。載入完成前不可儲存。
- 有修改取消／離開時提示；送出中顯示「儲存中…」並停用操作，失敗保留輸入。
- 成功提示「跟進紀錄已更新」，回跟進紀錄第 1 頁並重新排序；取消回來源頁碼。
- 停用會員仍可依方案權限更正歷史，辦理續約按鈕仍停用。
- 不顯示未實作的修改時間、修改者或修改歷程標記；聯繫時間不因編輯內容而自動變成現在。
